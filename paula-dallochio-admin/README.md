# Paula Dallochio Studio App

This folder contains the actual Sanity Studio application for `paula-dallochio-sanity`.

Esta carpeta contiene la aplicacion real de Sanity Studio para `paula-dallochio-sanity`.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
npm run build:ci
```

## Notes

- Sanity auto-updates are disabled in `sanity.cli.ts`, so both `npm run build` and `npm run build:ci` are safe for unattended validation.
- The main schemas are defined in `schemas/`.
- The project name has been aligned with the current folder name: `paula-dallochio-admin`.
